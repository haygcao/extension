OpenClip Sync - Fast, Secure & Multi-Device Clipboard Manager

The most secure multi-cloud clipboard history manager for Chrome - fully open source, privacy-focused, and packed with powerful multi-device synchronization features.

🚀 Key Features of OpenClip Sync:

• Multi-Cloud Synchronization: Sync your clipboard history seamlessly across devices using WebDAV (with Gzip compression), Chrome Sync, OneDrive, and Google Drive.
• Device Discovery Wall: View all active devices in real-time, inspect last active timestamps, and pull history from specific devices with a single click.
• Keyword Auto-Purge Rules: Set multi-keyword full-match blacklist rules to automatically purge sensitive text and logs.
• 100% Full Metadata Retention: Preserves pins, favorites, custom tags, and exact timestamps across all your connected devices.
• Privacy & Security First: Zero third-party telemetry, local-first data model, and transparent open-source codebase.
